# Fisiodar 🏥

Sistema de gestión y reserva de turnos para el centro de fisioterapia Fisiodar. Este proyecto está diseñado para demostrar habilidades como desarrollador Fullstack usando un backend robusto en Go y un frontend interactivo y optimizado en Next.js/React.

## 🛠️ Stack Tecnológico

- **Frontend:** Next.js (React) + TypeScript + Tailwind CSS (para diseño rápido y limpio)
- **Backend:** Go (Golang) con arquitectura limpia + PostgreSQL como base de datos relacional
- **Autenticación:** JWT (JSON Web Tokens)
- **Notificaciones:** Integración simulada/real para envíos de correo/SMS (recordatorios de citas)

## 📁 Estructura del Proyecto

El repositorio está organizado como un monorepo básico:
- `/backend`: API de Go, migraciones de base de datos y lógica de negocio.
- `/frontend`: Aplicación cliente y panel de administración en Next.js.
